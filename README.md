# michmidterm

Michigan midterm quiz iPhone app (SwiftUI demo).

## About
This repo contains a simple SwiftUI iPhone app that implements a 10-question informational quiz about Michigan midterm elections. The app is a demo and not affiliated with any government organization.

## Run locally
1. Open the Xcode project in this workspace (the project folder).
2. Select an iPhone simulator and press Run.

## Files included
- MyApp/
  - ContentView.swift (quiz UI)
  - MyApp.swift (app entry)

## Notes
- This is a minimal demo. Feel free to extend the quiz, add explanations, or persist results.
